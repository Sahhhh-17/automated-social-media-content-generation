Automated Social Media Content Generation

Overview

An AI-powered social media content generation and automation system developed using n8n and Generative AI. The project integrates Google Sheets, AI services, and LinkedIn to streamline social media content creation and publishing.

Technologies Used

- n8n – Workflow Automation
- Generative AI – Content Generation
- OpenRouter – AI Model Integration
- Google Sheets – Data Management
- LinkedIn API – Social Media Integration

Key Features

- Automated social media content generation.
- Integration with Google Sheets for input management.
- AI-powered content creation.
- LinkedIn integration for content publishing.
- End-to-end workflow automation.

Workflow

The system retrieves input data from Google Sheets, processes it through an n8n workflow, generates content using an AI model, and integrates with LinkedIn for publishing.
